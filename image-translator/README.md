# 图片繁体转换（本地测试版）

选择商品图片，识别其中的简体文字，转换为繁体并局部替换，保存为新的 PNG。免费本地处理，不需要 API 密钥。它是独立工具，和 Chrome 采集插件分开运行。

## 直接使用 Windows 便携版

1. 将 ZIP **完整解压**到普通文件夹。保留 exe 旁边的 `_internal` 文件夹。
2. 双击 `启动图片繁体转换.cmd` 或 `TraditionalImageTool.exe`，浏览器会自动打开操作页。启动窗口请保持打开。
3. 选择或拖入图片，填写完整输出文件夹路径，点击“转换并保存”。等待进度结束，查看原图与转换后的对比。

支持 Windows 10/11 64 位。首次使用加载本地模型会稍慢。如果浏览器没有自动打开，可复制启动窗口显示的 `Local URL` 到浏览器。每次启动的端口可能不同。

用完点击页面“退出工具”，或在启动窗口按 Ctrl+C。单独关闭浏览器页面不会关闭程序。该网址只在这台电脑上有效；别人需要解压并启动自己的副本。

## 输出与限制

- 每批 1–20 张静态 JPG、PNG、WebP，总上传不超过 80MB；单张不超过 1600 万像素或单边 16000 像素。
- 输出路径指向**运行程序的电脑**。可填写 `D:\图片输出`，文件夹不存在时自动创建。
- 每张生成 `原文件名_繁體.png` 和同名 `.json` 识别记录；重名自动加编号，原图保留。
- 页面列出识别的文字、繁体文字和跳过原因。只保存最近四批的页面预览，早期输出文件仍在指定文件夹中。
- 可选通用、台湾、香港繁体。这是字词转换，不做广告文案改写，也不更改图片中直接印刷的产品信息。
- 清晰的横排字、简单背景效果较好。花字、渐变、描边、小字或倾斜文字可能跳过或替换不理想。识别也可能出错，必须预览核对。新字体无法完全复制原字体。
- “替换 0 处”可能是识别不到、没有需要转换的字，或不适合安全替换；此时输出为原图副本，不能当作转换成功的证明。
- 保留原图尺寸（按照片 EXIF 方向摆正）、透明度；只修改识别文字附近区域。文字区域存在不均匀透明度时保留原样，避免破坏透明字形。
- 运行时使用本地模型和字典。工具不会把图片发给远程接口；浏览器与程序仅通过本机地址通信。
- 需要系统安装支持繁体的字体，如微软正黑体；程序不附带 Windows 字体。

## 从源代码运行 / 构建

需 Python 3.12，安装依赖：`python -m pip install -r requirements.txt`。开发安装依赖需要网络；便携版使用不需要重新安装。

运行：`python run.py`。可指定 `--output-dir "D:\图片输出"`，或 `--no-browser --port 8765`。

测试：`python -m pytest tests -q`。在 Windows PowerShell 构建：`./build.ps1 -Python "你的python.exe完整路径"`。构建输出在仓库 `artifacts/image-tool-build/dist/TraditionalImageTool`，完整复制该文件夹后可分发。

依赖与模型的许可说明见 `THIRD_PARTY_NOTICES.md` 及便携版 `licenses` 文件夹。
