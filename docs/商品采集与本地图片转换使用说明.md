# 商品采集与本地图片转换 1.6.4

## 第一次使用

1. 在 Chrome 扩展程序页面加载交付文件夹中的“商品采集插件”。已安装旧版时，在旧版详情中确认加载路径，改为新版文件夹或替换旧目录后重新加载。
2. 启动交付文件夹中“本机图片转换工具”的“启动豆包图片转换.cmd”。免费豆包模式需要电脑上安装 Chrome；阿里云模式不需要打开 Chrome。
3. 在本机工具页面复制“连接码”，粘贴到采集插件的图片转换区域并连接。连接码只用于当前工具进程，不要发送给其他人；工具重启后复制新码重新连接。
4. 免费模式：点击“打开豆包”，在工具弹出的专用 Chrome 中手动登录。普通 Chrome 或 Codex 侧边栏里的登录不能共用。阿里云模式不需要登录豆包，配置方法见下文。

## 转换采集图片

1. 按原来的方式输入商品名称，在拼多多、1688 或淘宝采集；等待采集结束，也可以先停止采集后处理已有结果。
2. 先在本机工具配置 OSS 并检查上传与公开读取（见《OSS开通与商品Excel图片替换说明》），返回插件刷新配置状态，无需选择本地保存文件夹。
3. 勾选要处理的“主图”“详情图”“SKU 图片”，默认全部勾选。“主图”包含采集到的主图轮播组，不只第一张。每类旁边可填写“前多少张”，数量按整批商品累计，留空表示全部；必须是正整数，未勾选类型不处理。按当前商品与图片顺序取前 N 个位置，再做网址和内容去重，不因下载或生成失败向后补足。至少选一类。
4. 默认使用免费豆包。豆包生成结果同样上传 OSS，成功后自动替换 Excel 图片链接，并非只保存在本地。需要付费接口时勾选“使用阿里云付费翻译”，核对选中图片数及费用估算，点击“付费开始转换”。工具依次下载并处理图片；相同完整地址或完全相同内容只转换一次。相同图片属于不同商品、类型或 SKU 时分别保存对应关系。
5. 本批开始后图片类型、数量限制、模式和 OSS 目标固定。暂停、继续或恢复均沿用本批清单；调整数量用于新批次，已完成的图片链接不会回退。新采集的商品需要下一批再次转换；不会自动切换到付费接口。豆包遇到验证码、登录或额度提示时需在专用 Chrome 中处理，再点击继续。阿里云模式不打开专用 Chrome。
6. “继续获取此图”用于下载同一张已经生成的图片；“重新生成”会再次调用所选服务，阿里云可能再次计费。正常关闭会清除临时任务，OSS 图片与插件已保存的替换链接保留。
7. 点击“导出 Excel”：已转换、上传并校验成功的位置使用 OSS 新链接，其他位置保留原图；无需等整批完成。不再提供 XLSX 图片清单。

## 阿里云开通与配置

1. 在自己的阿里云账号开通机器翻译的“电商图片翻译”服务。使用的是机器翻译 TranslateImage 接口，资源包要选择电商图片翻译，不能使用通用翻译资源包抵扣。
2. 建议创建独立 RAM 用户的 AccessKey，授予 `alimt:TranslateImage`，资源为 `*`。密钥只在本机工具页面填写，不要粘贴到聊天窗口、商品插件或 Git 仓库。
3. 在本机工具页面填写 AccessKey ID 和 Secret，点击保存配置。配置使用 Windows 当前用户加密保存在本机，工具正常关闭和清空任务后仍保留；可在配置区域删除。复制程序给其他人不会携带你的配置，他们需要配置自己的账号。
4. 返回插件重新读取配置状态，勾选付费模式。选择图片类型后，检查费用并点击“付费开始转换”。保存配置本身不会发起翻译或扣费。

固定翻译方向为简体中文 → 繁体中文，电商接口开启商品主体文字过滤，包括商品和包装上的文字。两种模式的保护结果都需要对照原图检查。

按 2026-10-08 查阅的官方价，电商图片翻译后付费为 **0.06 元/张**，主账号每月 100 张免费额度，子账号共享。工具按选中图片的独立网址数显示本次初始费用上限，不假定账号还剩免费额度；下载后的内容去重、失败及资源包抵扣可能减少费用。实际账单以阿里云为准，**无文字图片提交也可能计费**。

- [官方计费说明](https://help.aliyun.com/zh/machine-translation/product-overview/pricing-of-image-translation)
- [接口、权限与商品文字保护](https://help.aliyun.com/zh/machine-translation/developer-reference/api-alimt-2018-10-12-translateimage)

接口要求图片不超过 10MB、宽高在 15～8192 像素之间、长宽比小于 10:1。过长详情图会明确失败，工具不会静默裁剪或缩小；本版沿用静态 JPG/PNG/WEBP 限制。

## 付费请求失败与恢复

权限不足、服务未开通、额度/账户问题会暂停本批，请先在阿里云或本机配置中处理。明确单张图片问题会记录失败并继续其他图片。

结果图片下载失败时点击继续获取，只下载已经返回的图片，不再调用翻译。请求超时或是否提交成功不确定时会暂停，普通继续不会自动重提；明确选择“重新生成”可能再次计费。进度里的调用次数是本机记录的提交尝试数，不等于阿里云最终计费张数。

## 保存的内容

插件采集批次只保存到 OSS，不要求选择本机输出目录。处理时工具在自己的任务目录暂存原图和转换图；上传并持久保存已验证链接后删除图片缓存。上传失败保留临时图，点击“重试上传”只上传，不再翻译。异常退出后可恢复缓存；正常关闭或清空任务会清理临时文件。

结果对比从原图地址和 OSS 地址读取。刷新或关闭工具后，插件已保存的替换链接仍能用于导出。清空采集任务会清除对应链接；已上传 OSS 图片不自动删除。

工具重启需要复制新连接码重新连接。旧批次仍按开始时的配置继续；以前手动选择位置保存的图片不会被删除。工具独立选择本地文件的流程仍支持本地输出，与插件云端批次分开。

## 图片效果

默认只把商品和包装之外的广告文字转为繁体；商品/包装上的简体字、品牌、数字、图案必须保留。换背景和调整排版默认关闭。豆包生成结果需要逐张核对，不能保证所有字都转换正确或商品细节完全不变。免费网页生成的 AI 水印保留；遇到额度限制时需要等待服务恢复，工具不会绕过验证。
