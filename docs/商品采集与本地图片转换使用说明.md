# 商品采集与图片转换 1.6.6

交付文件夹仍名为“商品采集与图片转换_1.6.1”，这是保留的历史名称，里面的插件和后台组件均为 **1.6.6**。请解压完整目录后使用。

## 首次安装：只登记一次插件编号

1. 在平时登录商品网站的 Chrome 中打开 `chrome://extensions`，开启“开发者模式”，加载交付目录里的“商品采集插件”文件夹。
2. 点击插件图标打开管理页，在图片转换安装帮助中点击“复制插件编号”。编号为 32 位小写字母，不是密钥或日常连接码。
3. 双击“本机图片转换工具/安装后台组件.cmd”，粘贴完整编号。无需管理员权限，安装到当前 Windows 用户目录，只允许当前登记插件连接。
4. 回到插件点击“重新连接”，或重开管理页。以后只打开插件，后台自动启动，不需要每天运行 CMD 或复制连接码。
5. 免费豆包模式点击“打开豆包”，在专用 Chrome 手动登录并处理验证码。日常 Chrome 或其他浏览器的登录不能共用。阿里云模式无需打开豆包。

首次安装及自动启动不提交图片、不调用付费翻译、不自动检查 OSS。后台不可用时，商品采集、查看结果和已有 Excel 导出仍可使用。

## 升级与卸载

升级前停止后续转换提交，等待已提交图片安全保存。覆盖原来已加载的插件目录，在 Chrome 扩展页重新加载，确认版本 **1.6.6**。保持原加载路径，避免编号变化导致原采集数据看似丢失。从旧版升级或更新后台时，再运行新版“安装后台组件.cmd”登记当前编号。重复安装更新同一后台目录，保留加密配置、豆包登录和恢复记录；若提示后台仍在安全保存当前图片，等待后重试，不要强行结束或覆盖程序。移动插件目录导致编号变化时需重新登记。

运行“本机图片转换工具/卸载后台组件.cmd”移除本组件程序和当前用户登记，默认保留用户配置、登录、任务记录、已输出图片和 OSS 对象。仍在收尾时等待后再试。插件可在 Chrome 扩展页单独移除，移除插件会影响该插件的本机采集数据。后台不设置开机启动，不安装 Windows 系统服务。

## 转换采集图片

1. 按原流程在拼多多、1688 或淘宝采集，等待采集结束，或先停止采集后处理已有结果。
2. 在插件“图片服务设置”保存 OSS 配置，点击“检查上传与公开读取”。开通步骤见《OSS开通与商品Excel图片替换说明》。无需本机输出文件夹。
3. 勾选主图、详情图、SKU 图片，默认全选。主图包含轮播组。各类“前多少张”按整批商品累计，留空全部，填写时须为正整数。按商品与图片顺序先取前 N 个位置，再按网址和内容去重，失败不向后补图，至少选择一类。
4. 默认免费豆包。使用阿里云前保存翻译凭证，勾选付费模式，核对图片数及费用估算，再点击“付费开始转换”。仅明确开始或重新生成才提交，采集结束和重连不会自动开始。
5. 默认只转换商品及包装之外的广告文字。“同时转换商品及包装文字”默认关闭；开启后两种服务都处理商品和包装文字，数字、单位、原意与外观仍要求保持。豆包换背景、调整排版默认关闭，阿里云仍调用电商接口。每张结果需对照检查。
6. 开始后图片清单、类型、数量限制、服务、文字范围和 OSS 目标固定，暂停、恢复和重新生成沿用。补采商品不自动加入；调整选项需新批次，已完成链接不回退。
7. 每张结果上传 OSS 并公开读取校验通过后，保存商品、类型及 SKU 的对应关系。相同网址或完全相同内容只生成一次，各位置关系分别保存。免费豆包网页的 AI 水印保留。
8. 随时导出 Excel：成功位置使用 OSS 链接，未完成或失败位置保留原图。XLS/XLSX 的 22 列模板、价格及 SKU 行不变，不再导出图片转换清单.xlsx。

## 插件里的阿里云和 OSS 设置

在自己的阿里云账号开通机器翻译的电商图片翻译，资源包须选择电商图片翻译，通用翻译资源包不能抵扣。建议独立 RAM 用户授予 `alimt:TranslateImage`，资源为 `*`，在插件“图片服务设置”填写 AccessKey ID 和 Secret 后保存。

配置继续使用 Windows 当前用户 DPAPI 加密，保存后输入框清空，状态仅显示是否配置等必要信息，不回显 Secret。密钥不保存到 Chrome 存储、商品任务、Excel、日志或交付包；可在设置中删除。用户数据默认位于 `%LOCALAPPDATA%\DoubaoImageTool`，不要分享该目录。

OSS 在同一区域填写 Bucket、地域与凭证来源，可复用翻译 AccessKey 或用独立 OSS 凭证。保存配置不上传；**只有明确点击“检查上传与公开读取”才上传小测试图**，可能产生少量请求、存储和读取费用。正式图片的 OSS 存储、请求和公网读取费用另计。

按 2026-10-08 查阅的官方价，电商图片翻译后付费参考价为 **0.06 元/张**，主账号每月 100 张免费额度、子账号共享。费用预览按选中独立网址数计算初始上限，不假定剩余额度；内容去重、失败和资源包抵扣可能减少费用，实际以阿里云账单为准。无文字图片提交也可能计费。

- [官方计费说明](https://help.aliyun.com/zh/machine-translation/product-overview/pricing-of-image-translation)
- [接口、权限与商品文字保护](https://help.aliyun.com/zh/machine-translation/developer-reference/api-alimt-2018-10-12-translateimage)

固定简体中文 → 繁体中文。默认电商接口开启主体文字过滤，包装文字开关启用后关闭过滤，接口与资源包类型不变。图片最多 10MB，宽高 15～8192 像素，长宽比小于 10:1；沿用静态 JPG/PNG/WebP 限制，超长详情图明确失败，不静默裁剪或缩小。

## 停止、关闭和恢复

关闭或刷新管理页不清空采集清单、转换任务及已保存链接；再次打开自动连接并恢复同一来源批次。已有其他采集来源的转换任务时，插件显示冲突，需要明确清空旧转换任务，不把旧结果写入新商品。

完全退出 Chrome 或原生通道断开后，后台留出 **30 秒重连宽限**。持续断开后停止新提交，对已提交的当前图片继续取回、上传和保存；收尾等待最多 **600 秒**，随后保留任务记录并退出。浏览器自身结束可能增加有上限的时间。超时不重新提交不确定请求。再次打开或重连仅恢复状态，须明确点击继续。

“停止后续提交”保留已发送请求；“继续获取此图”仅取回同一结果；“重试上传”仅上传已有缓存；“重新生成”再次调用服务，阿里云可能再次计费，需确认。超时或提交不确定时先检查状态，普通继续不自动重提。登录、验证及额度需在专用 Chrome 或相应账号处理。明确单张图片问题可记为失败继续，权限、服务和账户问题会暂停。

插件批次仅保存到 OSS。后台暂存原图和转换图，成功链接持久保存后清理图片缓存；上传失败保留缓存，自动安全退出保留 DPAPI 配置、来源任务及恢复记录。插件已保存链接仍可直接导出。“清空转换任务”安全结束处理后清理临时记录及缓存，保留凭证、登录、OSS 对象和插件已保存链接；“清空全部”采集任务则清除该任务的替换关系，已上传对象不自动删除。

## 独立工具兼容入口

仅需选择本机图片、保存到本机时，可单独运行“本机图片转换工具/启动豆包图片转换.cmd”，在独立工具页选图并填写输出目录，每批 1～20 张。它与新版插件流程分开，日常采集转换无需打开此页面。旧插件的手动连接码仅用于旧版兼容，当前进程重启后失效。

独立工具的“关闭工具并清空任务”清理临时任务及缓存，保留加密配置、豆包登录和已输出文件。此显式清空与新版插件后台自动退出保留恢复任务不同。独立流程详见本机工具 README。

## 本版验证边界

已验证隔离真实 Chromium 的原生连接、后台自动启动、插件设置与真实 Windows DPAPI、密钥清空、刷新恢复、部分 XLSX 导出，以及编译程序双主机复用同一后台。商品、结果链接为受控样本，外部翻译及上传为假实现。本轮真实付费调用为 0，未做真实 OSS 上传、在线商品整批采集或真实生成图的文字正确性验收。实际账号权限、额度、网络及页面变化仍需使用时确认，图片效果需人工检查。
