# 拼多多商品链接收集插件设计草案

状态：用户已确认；已实现第一版。2026-09-27 用户追加：Excel 须按其提供的“导入产品模板.xls”格式输出；添加名称立即搜索，收集 20 条即切换。用户现场反馈插件从搜索页进入商品详情后曾错误暂停；已按该导航路径修正，待用户 Chrome 复测。

## 使用流程

1. 打开插件的独立管理页，输入一个商品名称，点击“添加”或按回车。
2. 名称加入列表并保存在浏览器本地，关闭管理页、重启浏览器后仍保留。空白名称不添加，重复名称不重复添加；列表支持删除。
3. 添加名称后立即开始搜索；运行中继续添加的名称进入同一队列，当前名称完成后自动搜索下一个。
4. 收集商品主图、商品 ID、标题、展示价格和详情链接，按主图分组；每组保留展示价格最低的一条。
5. 每个名称选出最多 20 组不同主图的商品，每组输出一个链接。
6. 完成后提供“导出 Excel”按钮，默认生成与用户模板同类型的 .xls 文件，也提供同布局 .xlsx 选项，由用户选择保存位置。

## 建议采用的比较范围

- 每个名称默认最多扫描 200 个结果卡片；到达列表末尾时提前结束。
- 收集到 20 组后立即切换到下一个名称，不再为同图更低价继续扫描。
- 最后按各图片组首次出现的顺序选出前 20 组，并输出每组扫描范围内最低价的商品。这不是从全部组中选择价格最低的 20 组。
- “最低价”仅指本次实际扫描的结果中的最低展示价格，不代表全平台最低，也不验证商品规格或结算价相同。
- 不足 20 组时导出实际数量并说明原因，不重复补足。

## 主图去重和价格规则

- 商品 ID 相同的结果先合并，过滤同一商品的重复展示。
- 主图相同或高度相似的不同商品归为一组，跨店铺也执行相同规则。
- 优先在本地计算图片相似度，兼顾尺寸变化和轻微压缩；对裁剪、文字覆盖的识别需要用样本调试，不能保证无误判。
- 图片无法读取或比较时，不把该结果默认为独立主图；跳过并在任务统计中记录。
- 价格取卡片明确展示的当前售价或券后价；无法可靠解析或价格含义不明的结果跳过并记录。
- 同组同价时保留先出现的商品。
- 每个商品名称独立去重；不同名称可以包含同一链接。

## 界面和进度

- 商品名称输入框、添加按钮、已保存名称列表。
- 添加、暂停/继续、停止、导出 Excel 按钮；已处理名称可单独“重新搜索”。
- 总进度以已处理名称数 / 总名称数显示；处理期间不显示虚假的完成百分比。
- 展示当前商品名称、已扫描结果数、已识别图片组数和预计可输出数量（最多 20）。
- 单项结果状态：等待、搜索中、完成、数量不足、需处理登录/验证、失败。
- 运行中新添加的名称进入当前队列；结果持续累积，最后统一导出。

## 文件与任务保存

- 商品名称列表、运行检查点和已采集结果保存在 Chrome 本地存储，不需要账号密码输入。
- Excel 只有与用户模板同名的“模版”工作表：第 1–8 行字段说明、第 9 行原 22 列表头、第 10 行起商品数据。每个采集商品一行，产品主编号依输出顺序生成唯一编号；产品名称取商品标题，货币类型为 CNY，产品主图取采集主图，货源链接为商品详情链接，货源平台为拼多多，货源ID为商品 ID，SKU 售价为扫描到的展示价格。未采集的可选字段留空。
- 用户模板的示例商品不保留在导出文件。运行状态、跳过原因和数量不足仅显示在管理页，不混入平台导入表。
- 文本内容按文本单元格写入，商品名称和标题不能被解释为 Excel 公式。
- 未完成或被停止的任务也可以导出已有结果。
- 浏览器关闭或异常中断后恢复到暂停状态，由用户点击继续；避免重复输出。

## 技术选择

推荐采用 Chrome Manifest V3 插件，使用独立管理页运行任务控制和 Excel 导出，页面脚本读取搜索结果，后台负责标签页与消息协调。需要的表格和图片处理代码随插件打包，不在运行时加载远程代码。

相比仅依据图片地址去重，本地图片相似度能识别图片地址不同但画面相同的情况；相比接入外部图像服务，本地处理不增加外部账号和按次费用。因此第一版采用本地图片相似度。

只申请任务必需的存储、拼多多页面及实际图片来源访问权限；图片域名应依据实际页面确认，不能预先扩大为所有网站。

## 异常处理与验证

- 遇到验证码或登录失效时暂停，提示用户在原页面处理后继续。
- 插件为提取无直达链接商品 ID 而打开详情页后，明确导航回原搜索网址并恢复滚动位置，避免浏览器历史返回到非搜索页。
- 页面没有更多结果、加载失败、搜索失败要分别显示，不能把失败当成正常完成。
- 顺序执行搜索，设置页面等待和有限重试，避免并发打开大量搜索页面。
- 首先验证实际页面的搜索入口、结果卡片、图片读取和链接提取，确认后完成整条流程。
- 验证重点：不同 ID 的相同图片只输出一条且保留低价；20 组限制；不足 20 组；不可解析价格；暂停恢复；多名称进度；Excel 可正常打开。
- 目前工具未连接到用户的 Chrome，实际登录页面验证仍需后续完成。离线样本通过不等于实际页面已通过。
