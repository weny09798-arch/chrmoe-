# OSS 开通与商品 Excel 图片替换（1.6.4）

插件转换图片直接保存到你自己的阿里云 OSS，无需选择电脑文件夹。处理时的临时缓存由工具自动管理，上传成功后清理。上传并验证成功后，插件导出的商品 Excel 自动使用转换图片链接。中途停止也可导出，尚未完成的位置保留原图。不再需要额外的图片转换清单.xlsx。

## 先创建专用图片 Bucket

1. 使用阿里云主账号打开 [OSS 控制台](https://oss.console.aliyun.com/)，开通对象存储服务后，进入 Bucket 列表，点击“创建 Bucket”。OSS 与机器翻译是两个服务，费用分开。
2. 填写一个自己选择的 Bucket 名称，选择地域（例如华东 1 杭州，对应 `cn-hangzhou`），存储类型选“标准存储”，读写权限保持“私有”，不开启版本控制。
3. 在这个专用 Bucket 的公共访问设置中关闭“阻止公共访问”。如果账号级别也阻止公共访问，需要主账号调整相关设置。保持 Bucket 本身为私有；工具只给 `converted-images/` 下的转换图片设置公共读。
4. 不配置自动删除图片的生命周期规则。删除或收回这些图片的公共读取权限后，以前导出的 Excel 链接也会失效。

公开的是用于商品导入的图片，持有链接即可读取；工具不设置公开写入，也不会修改整个 Bucket 的读写权限。[Bucket 创建说明](https://help.aliyun.com/zh/oss/user-guide/create-a-bucket-4)、[单个文件权限说明](https://help.aliyun.com/zh/oss/user-guide/object-acl)。

## 给 RAM 用户授权

可以给之前图片翻译的 RAM 用户增加 OSS 权限，也可创建独立的 AccessKey 用户。工具不会自动创建 Bucket 或修改 Bucket 权限。

在 RAM 的“权限策略”中新建自定义策略，使用脚本编辑，粘贴下面内容；将 `你的Bucket名称` 替换成上一步真实名称，再授权给该 RAM 用户：

```json
{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["oss:PutObject", "oss:PutObjectAcl"],
      "Resource": ["acs:oss:*:*:你的Bucket名称/converted-images/*"]
    }
  ]
}
```

此策略只允许上传和设置专用前缀图片的权限，不允许修改 Bucket 或删除文件。图片翻译所需的 `alimt:TranslateImage` 权限继续保留。[官方上传权限和参数](https://help.aliyun.com/zh/oss/developer-reference/putobject)。

## 在工具里配置和检查

1. 关闭旧工具并启动固定交付目录中的“启动豆包图片转换.cmd”，找到“OSS 图片链接配置”。
2. 填写 Bucket 名称及地域代码，必须与控制台一致。选择“使用已保存的图片翻译 AccessKey”或“独立 OSS AccessKey”；独立方式需在工具里填写 ID 与 Secret。
3. 点击“保存 OSS 配置”。配置加密保存在当前 Windows 用户下，不发送给插件，不随程序复制给别人，也不会在保存时上传图片。
4. 点击“检查上传与公开读取”。这会上传一张很小的测试图片并读取验证，可能产生少量请求费用。成功后回到插件重新连接、刷新配置状态。
5. 勾选需要转换的图片类型，分别设置该类前多少张（留空全部），选择翻译模式，开始转换。豆包与阿里云模式共用 OSS 上传及商品 Excel 替换流程。OSS 会产生存储、请求和公网读取流量费用，实际以阿里云账单为准；豆包或阿里云翻译费用另计。

## 导出和恢复

- 每张图完成转换、OSS 上传和公开读取验证后，自动替换 Excel 对应位置。多商品共用同一张转换图时仍保持各自对应关系。
- 例如主图总共 20 张，完成 8 张后停止，再点击“导出 Excel”，得到 8 张转换图链接及 12 张原图链接。其他未勾选图片类型保持原图。
- 关闭本机工具、刷新插件或重新连接后，插件已保存的替换链接仍保留。清空采集任务后不再使用旧任务的链接；OSS 图片不删除，临时任务缓存清理。
- “重试上传”只上传已有临时转换图，不再次付费翻译。“重新生成”重新调用翻译服务，付费模式会要求再次确认；新结果验证成功前保留旧的可用链接。
- OSS 权限或配置问题暂停批次，请先修正权限或密钥。批次中保存目标固定，修改 Bucket 或地域需开始新批次。
- 刚升级时已有的旧批次可继续获取原结果，但不会悄悄上传到 OSS。新整合批次要求 OSS 配置完成后手动开始。

导出的 Excel 单元格仍是网络图片链接，不是内嵌图片或电脑路径。第一次请用少量商品实际导入货憨憨检查图片显示和文字效果，确认后再批量处理。
