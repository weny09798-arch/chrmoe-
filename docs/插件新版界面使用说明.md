# 插件新版界面使用说明（1.6.10）

管理页左侧的“通用功能”右边有展开箭头，点击可以展开或收起菜单。点击菜单项，右侧显示对应功能。

## 四个入口

| 菜单 | 可以做什么 |
| --- | --- |
| 商品采集 | 设置平台、数量、价格和主图去重，添加商品名称，查看进度、商品和重复项 |
| 图片转换 | 选择主图、详情图和 SKU 图及数量，选择豆包免费／阿里云付费，查看转换和上传结果 |
| 商品卖点图 | 上传单张图片，生成和编辑繁体卖点，制作、上传或下载卖点图 |
| 服务设置 | 查看后台连接、复制插件编号，配置阿里云翻译、OSS 和百炼密钥 |

淘宝访问间隔和“采集当前淘宝／天猫商品”入口在“商品采集 → 高级采集选项”中。

图片转换页点击“配置图片服务”会直接打开服务设置中的 OSS 配置。卖点图页点击“配置百炼服务”会打开百炼配置。密钥操作反馈显示在对应配置区。

## 切换页面与导出

切换功能页时正在进行的任务继续运行，当前输入、预览及进度保留。刷新页面恢复最后查看的功能页；任务刷新后的恢复、暂停规则沿用原流程，需要继续时手动点击继续。

“导出 Excel”和文件格式位于页面右上角，各个功能页都能使用。转换到一半也能导出：已上传验证成功的位置使用新链接，其他位置沿用原图。卖点图仍为独立单图工具。

窄窗口时，点击顶部左边的菜单按钮展开导航，选择功能后自动收起；也可点击外部遮罩或按 Esc 关闭菜单。

## 升级

1. 等待当前操作完成，关闭旧管理页。
2. 将新版“商品采集插件”文件夹里的内容覆盖原来加载的插件目录，保持目录路径相同。
3. 在 Chrome 的 `chrome://extensions` 页面找到插件，点击刷新，确认插件版本为 **1.6.10**，重新打开管理页。

本次只升级插件界面。已安装 **1.6.9** 后台的用户无需重装后台，原有配置继续使用。初次使用的用户先在“服务设置 → 后台连接 → 首次安装／连接失败说明”复制插件编号，再运行交付包里的“安装后台组件.cmd”。

交付目录继续为 `D:\Desktop\chrome插件\交付包\商品采集与图片转换_1.6.1`，压缩包继续为同位置的 `商品采集与图片转换_1.6.1.zip`。
