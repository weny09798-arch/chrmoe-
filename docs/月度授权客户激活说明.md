# 1.7.0 客户软件授权与激活

目前 1.7.0 仅完成源码与隔离验证，尚无正式授权服务或客户包。明确标记为 EVALUATION-LOCKED 的包保持锁定，不能用于正式采集与生成。现有可用 1.6.4 交付包仍可照常使用，旧版无法被远程追溯停用。

正式部署后，软件授权码由软件所有者提供。它与插件连接码、豆包登录、阿里云 RAM、AccessKey、OSS Bucket 均不同。软件授权不需要你先开通 RAM 或阿里云服务；选择阿里云翻译或 OSS 上传时才另外配置自己的服务账户与密钥。

## 首次激活

1. 在将长期使用的 Windows 电脑上启动本机工具，并保持能访问授权服务器。
2. 在“30 天软件授权”输入所有者提供的授权码，点击“激活授权”。首次成功激活立即开始连续 30 天（2,592,000 秒），按服务器时间计时。
3. 确认显示授权有效与到期时间。复制本机工具的“连接码”，在商品采集插件中连接。工具重启后重新复制连接码。
4. 完成软件授权后，选择需要的转换服务、图片类别与数量；使用收费服务时按页面确认。软件授权不会替你开通或支付第三方服务。

一枚授权码同时绑定一台 Windows 电脑，不能供第二台电脑使用。硬件标识来自 Windows MachineGuid 与系统卷 ID；读不到标识时会拒绝激活，不会随机生成替代标识。更换系统、重装或换电脑后若绑定不匹配，请联系所有者处理解绑。解绑只改变绑定，不重置或延长原到期时间。

## 续费、停用、到期与断网

所有者在管理后台续费，每次从“服务器当前时间”和“现有到期时间”的较大值追加 30 天。续费后点击“刷新授权”；任务仍保持暂停，需要你手动点击继续或重新开始。所有者自己的电脑遵循相同规则。

到期、停用、解绑或未获得有效授权时，停止新商品采集与新图片生成。已经提交的图片允许继续获取结果、上传并保存；已经成功的图片与商品数据仍可查看、导出。Excel 仅使用已有且成功校验的图片替换，未完成的位置仍保留原图，XLS/XLSX 的列、SKU 行与格式不因授权状态改变。

工具启动、开始工作前、工作中每 5 分钟验证。成功在线验证后最多允许断网使用 24 小时，并且不能超过软件到期时间。明确收到服务器拒绝后，原断网授权立即失效。系统时间回退要求重新在线验证。若工具关闭导致插件失去本机授权连接，新采集与生成会锁定；已有数据仍可导出。

## 本机授权与个人配置

授权码及签名缓存由 Windows 当前用户 DPAPI 加密保护，位于工具运行的本机配置目录。不要发送该目录或浏览器配置给其他人，也不要把它们放进软件压缩包。另一台电脑不能靠复制这些文件获得授权。清空任务保留软件授权、登录与阿里云/OSS 配置；如果删除本机配置，需要再次在线激活，但服务器原到期与绑定记录仍保留。

页面显示的“软件授权码”不要填成“插件连接码”或阿里云 Secret。遇到“未配置授权服务”，表示包尚未配置正式服务；“设备不匹配”需要所有者核对绑定；“已停用/已到期”需要所有者处理；“暂时无法连接”应恢复网络后刷新。不要为了激活而将软件授权码填写到 RAM 或 OSS 控制台。
