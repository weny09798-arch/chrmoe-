# 1.6.9 采集修复与主图去重

## 更新

覆盖原插件加载目录，在 Chrome 扩展管理页重新加载。版本应显示 1.6.9。新版本需要读取拼多多图片域名以比较原主图，Chrome 提示新增权限时按提示启用。

本轮继续使用固定交付目录“商品采集与图片转换_1.6.1”，名称未变，内容版本为 1.6.9。后台组件也使用对应版本；运行新版“安装后台组件.cmd”更新已安装副本，保留现有登录及加密配置。

## 淘宝异常与当前商品

看到“访问异常”“安全验证”或登录提示时，采集立即暂停，页面与已保存结果保留。先点击“查看采集页”处理页面；确认正常后点击“继续”。仍受限时继续保持暂停，不自动刷新和反复提交。

淘宝商品自动访问间隔默认 10 秒，可设更长；这只是减少访问，并不保证平台不会触发验证。旧账号或浏览环境本身受限时，需要先恢复正常手动浏览。

手动打开淘宝或天猫商品，在插件展开“采集当前淘宝／天猫商品”，点击“刷新标签列表”，选择目标后点击“采集当前商品”。工具使用已打开页面，不重新搜索，也不会关闭这个标签页。采集期间不要切换该标签的网址。结果进入商品列表，支持原有图片转换和 Excel 导出。

## 拼多多连续跳过

优先读取卡片真实链接和已加载数据；缺链接时恢复 1.5.7 的打开商品补充方式。找不到真实链接不会猜造。遇验证立即暂停；连续五条名称或链接无法识别时也暂停并说明原因，不再无休止跳过。

名称失败、链接失败、价格筛选、主图重复分别计数。价格筛选未命中不代表页面识别失败。

## 主图去重

新建搜索默认勾选“主图去重”，可以取消。只在同平台同一个搜索任务内生效，不跨名称或跨平台合并。旧任务保留原来按 ID 去重的行为；要使用新规则请新建搜索。

比较采集原图，不比较已翻译的结果。相同或高度相似主图默认保留先采集商品，重复商品不计入采集目标，继续向后补足数量。图像无法读取时保留商品并提示未完成去重，不因图片失败丢失链接。

“查看重复商品”保留原图、标题、价格和真实链接。若不同规格或不同商品被误合并，点击“保留为独立商品”，恢复后不再自动并回同组。手动恢复可超过原设定数量；每条商品仍使用自己的 SKU 和图片转换链接。

已采集商品和已成功上传的转换图继续支持中途导出；尚未成功转换上传的位置使用原图。图片相似判断不能替代人工检查商品规格。
