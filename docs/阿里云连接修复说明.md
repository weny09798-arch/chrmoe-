# 阿里云连接说明（1.6.6）

杭州接入地址已修正为 `mt.cn-hangzhou.aliyuncs.com`，原地址 `alimt.cn-hangzhou.aliyuncs.com` 不再使用。这是 2026-10-08 的连接修复，当前交付为 1.6.6。

新版操作：

1. 覆盖原插件加载目录并在 Chrome 重新加载，确认 1.6.6；不要换目录丢失原插件编号。
2. 在插件安装帮助复制完整 32 位插件编号，运行“本机图片转换工具/安装后台组件.cmd”登记。旧后台仍在保存当前图片时，等待后重试，重复安装保留加密配置、登录与恢复任务。
3. 回插件点击“重新连接后台”，在“图片服务设置”确认已配置状态；需要修改凭证时就在插件输入并保存。以后自动连接，不需要启动独立工具、复制连接码或选择本机保存目录。
4. 选择图片类型及数量，核对付费估算，明确点击“付费开始转换”才调用服务。重新连接不会自动重提此前不确定的请求，重新生成可能再次计费。

独立本机选图可以单独运行启动 CMD，是兼容入口，与新版插件流程分开。

[阿里云官方接入地址说明](https://help.aliyun.com/zh/machine-translation/developer-reference/api-alimt-2018-10-12-endpoint)。2026-10-08 仅验证正确域名 DNS 与无凭证 HTTPS 请求；本次统一入口使用受控服务测试，真实付费调用为 0，未使用真实密钥在线翻译。费用以阿里云账单为准。
