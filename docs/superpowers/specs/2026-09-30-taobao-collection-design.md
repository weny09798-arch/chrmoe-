# 淘宝采集接入

按用户要求，输入淘宝网址后在淘宝搜索，采集与现有 1688 相同的模板字段，并使用既有数量、价格、主图去重、删除补齐及导出流程。用户已要求实施此扩展；常规实现选择由代理处理。

选择沿用登录 Chrome 网页读取方案：比增加外部采集服务更符合现有操作，也不需要额外账号；仅保存搜索链接无法满足详情及 SKU 需求。保留现有拼多多和 1688 适配，不进行无关重构。

新增淘宝站点路由、搜索卡片读取器和详情读取器。淘宝搜索可能出现天猫详情链接：保留对应商品详情域名，货源平台按实际链接区分淘宝/天猫。输入淘宝网址仍从淘宝搜索。接受 HTTPS 淘宝网址；天猫网址可使用同一搜索流程。只接受已知官方商品地址和数字 ID，拒绝伪造相似域名及外部跳转。

搜索读取商品标题、主图、明确展示价格和 ID，不把促销、销售量及店铺名当标题或价格。支持列表滚动及明确的下一页控件；保持任务数量上限、历史去重和 200 条扫描上限。完成目标即结束，平台登录或验证码保留进度由用户处理。

详情优先读取页面已经提供的当前商品数据，使用商品 ID 约束，排除推荐商品；兼容初始化 JSON 及主页面数据。按 SKU 的 propPath 与规格值映射组合名称，并按 skuId 对应价格、库存和图片，不复制搜索价格制造多个 SKU。DOM 只补充真实可见标题、主图、详情、参数、视频及明确 SKU 行；无法获取完整 SKU 时标为部分采集，不声称完整。

输出字段为名称、主图、货源链接/平台/ID、描述、详情图、类目、自定义属性、视频、证书、尺寸图表、规格、SKU ID/价格/图/库存/重量/尺寸。字段仅填页面提供的值，不凭空补证书或库存。模板及两列 SKU 规格限制沿用现有导出。

只读取正常已打开页面，不调用未公开接口、不截取账号凭据、不绕过验证码。新增淘宝网页权限，图片复用已有 alicdn 权限。官方详情文档只用页面提供的 HTTPS 地址和已允许来源读取。

验收：站点/任务保存、淘宝及天猫链接、分片价格、标题清理、分页、当前商品数据约束、SKU 映射、延迟详情、登录阻断、Excel 多 SKU 行、旧站点回归、打包副本一致。浏览器安全策略阻止开发环境访问淘宝，所以以受控样本验证并明确实站未验证。
