# 淘宝翻页中断修复

用户截图显示 `s.taobao.com/search?page=1&q=玉石手电筒&tab=all` 底部仍有可用的“下一页”，插件却以未识别到结果失败。代码的翻页选择器仅支持链接和按钮，且 Runner 在重复/空快照时没有翻页等待状态；截图无法确认当前控件的 HTML 标签，因此用受控页面覆盖不同标签与加载过程，不宣称实站复现。

采用页面上的真实下一页控件，支持分页区内 div/span/role/button 与官方搜索链接，排除禁用、隐藏、商品卡片和外站链接。相比直接拼接页码，真实控件可以保留页面筛选条件；相比单纯延长等待，显式翻页状态能区分已请求翻页与普通停滞。

翻页请求只发一次，等待新商品列表后才继续扫描；等待期间禁止重复点击或处理旧列表，保留原结果。等待最多 25 秒；未完成时明确报告翻页失败，不无限重试。验证码/离开搜索结果仍使用原阻断流程。最后一页有禁用下一页时结束；达到设定数量立即停止，不翻页。Runner 的停滞判断包含页面标识，并对翻页等待使用有限等待上限。

验证范围：不同控件标签、非分页下一页、外站链接、禁用祖先、延迟加载、多页采集、达到目标、真实末页、失败重试与已有结果提示。当前开发浏览器此前阻止淘宝访问，不更换工具绕过；仅使用截图和本地受控页面验证。
