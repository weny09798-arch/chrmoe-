# 插件管理界面改版设计草案

状态：用户已确认“可以”，按本设计实施。参考用户提供的蓝白色左侧折叠菜单截图。

## 目标

把现有长页面改成左侧导航、右侧工作区，使商品采集和图片转换各自占一个功能页。保留卖点图和服务配置入口，让客户容易找到当前需要的操作。

## 布局与视觉

- 左侧固定导航栏，顶部显示插件名称，下方为默认展开的“通用功能”分组；分组右侧箭头支持展开、收起，并通过 aria-expanded 表达状态。
- 分组内依次显示“商品采集”“图片转换”“商品卖点图”“服务设置”。当前项使用蓝色文字、浅蓝背景和左侧蓝色标记，参考截图的选中效果。
- 右侧顶部显示当前功能名称和后台连接状态，下方显示对应工作区。采用浅灰页面背景、白色卡片、蓝色主要按钮，统一输入框、表格、提示和间距。
- 首次打开默认显示商品采集；刷新恢复上次查看的有效功能页。非法或已移除的页面标识回到商品采集。
- 窄窗口中保留可操作的折叠菜单入口，内容单列排列，表格允许横向滚动，避免整个页面横向溢出。

## 页面内容

### 商品采集

上方显示采集统计和“导出 Excel”，主体保留采集设置、商品名称队列、任务进度、结果列表、已收集链接和重复商品。当前商品辅助采集、淘宝访问间隔等低频选项放在清晰的折叠区域内。宽窗口中采集设置和结果左右排列，窄窗口改为上下排列。

### 图片转换

保留类型勾选及数量限制、豆包／阿里云选择、包装文字开关、费用提示、开始／停止／继续／清空、进度及原图结果对比。页面提供切换至服务设置的按钮；服务未配置时的提示可直接带用户到对应配置区域。提供导出入口，复用同一导出逻辑，在转换中途也能导出已完成替换的 Excel。

### 商品卖点图

保留单图上传、商品资料、生成文案、编辑文案、制作图片、结果预览、上传重试和下载。百炼密钥配置移至服务设置，并提供跳转入口。

### 服务设置

集中显示后台连接和安装说明、阿里云图片翻译配置、OSS 配置及连通检查、百炼配置和教程。复用现有字段和操作，不重复创建密钥输入框。敏感字段沿用现有保存后清空规则。

## 页面切换与任务状态

- 四个功能页使用同一个管理页面内的独立视图，不通过重新加载整个页面来切换功能。
- 导航仅切换视图可见性，后台连接、采集运行器、转换轮询、卖点任务和现有输入内容保持有效。
- 所有原有控件 ID、业务事件和任务保存规则继续复用；新增导航模块只负责导航和界面状态。
- 多处导出入口使用同一操作和相同禁用条件，导出仍按当前已保存替换关系生成。
- 隐藏页面不进入键盘操作顺序；导航支持键盘与可见焦点。状态提示保留现有辅助阅读语义。

## 方案选择

推荐左侧折叠菜单配合单页视图：符合截图，也能在切换功能时保留任务。顶部标签页占用更少空间，但不符合这次参考样式；分成多个真正的 HTML 页面需要额外处理运行任务和连接迁移，本次采用单页视图实现独立工作区。
