# 商品图片预览、删除与自动补齐

日期：2026-09-30

## 用户需求

在管理页“查看已收集的商品链接”列表显示每个商品采集到的第一张主图。每行提供删除 ×，删除不需要额外确认。保留其余选品，并再次搜索对应名称，补齐该任务保存的采集数量要求。用户已授权自行决定补搜时机。

## 展示

列表增加“商品图片”和“操作”列。缩略图优先使用 galleryImages 中第一个有效 HTTPS 地址，缺失时使用搜索结果的 image。图片延迟加载，不携带来源页面信息；失败时显示“暂无图片”。保留原有标题、价格、详情说明和商品链接。删除按钮包含商品名称的可访问标签。

## 删除与排除

删除整个按主图去重的商品组，同时排除该组全部已知商品 ID、代表图片和图片指纹。排除记录按商品名称任务保存至本机。后续候选同时检查 ID、相同图片和现有相似主图规则，避免同图其他店铺重新出现。保留其他商品详情和数量、价格、来源设置；导出只包含仍保留的商品。手动“重新搜索”继续保留排除记录；“清空全部”清除全部排除记录。

## 补搜调度

选择延迟约 1 秒自动补搜。相比立即重启，它可以合并连续删除，减少搜索中断；相比增加手动补齐按钮，它符合用户要求的自动补搜流程。

删除立即更新列表、计数和已保存结果。若采集正在运行，请求安全暂停，等待当前页面操作结束并清理详情标签后，再变更搜索阶段及启动补搜，避免旧结果回写或并行搜索。待补任务按原顺序处理，其他名称的结果保留。

每次删除引发的补搜重置本轮扫描预算，最多检查 200 条新候选；保留历史 seen，滚动经过旧结果后继续检查未处理候选。达到任务的 limit 即结束搜索，再仅补全新增商品详情。补搜结束仍不足时展示实际数量和结束原因，不循环重启。平台验证或登录阻断时保留结果并提示继续；用户主动暂停或停止取消已安排的自动补搜，之后由“继续”恢复。清空取消计时和待删任务，等待活动操作结束后清除全部数据。

## 数据与兼容

旧任务没有排除字段时按空列表处理。图片展示不需要增加 Chrome 权限。使用当前多来源架构，拼多多和 1688 共用删除与排除逻辑。此次只修改列表、任务管理与候选筛选，不覆盖工作区中其他采集适配改动。

## 验收

- 有多张主图时显示第一张，缺失或图片请求失败时有占位。
- 删除后结果和 Excel 不再出现该商品，已知 ID 和相似主图都不能被再次加入。
- 连续删除合并补搜，已有商品及其详情保留，按每个任务保存的 limit 补齐。
- 在候选读取、图片下载和详情读取过程中删除，不会由迟到的回写恢复被删商品。
- 到达目标后停止，搜索末尾或扫描上限不足时说明原因。
- 暂停、停止、平台验证、关闭后恢复、清空与补搜交互不会产生第二个并行采集任务。
- 自动化验证后将本次相关文件同步至交付目录，核对文件一致性并打包；保留其他未提交改动。
