# 商品 ID 去重与详情图片

用户已同意上一条消息中的方案。三个来源（拼多多、1688、淘宝）统一按商品 ID 保留链接，不再按图片合并，也不再承诺同图最低价。搜索仍校验名称关联、明确价格和用户价格范围；缺图片不阻止保留。淘宝只有名称/价格缺失才等待列表重读。

每个名称达到数量后，自动通过现有后台详情页流程补全图片、SKU、描述等字段。使用详情相册第一张有效 HTTPS 图片展示和导出；没有可用图片时保留链接，明确显示缺图片。详情页登录/验证码仍暂停，普通失败只标记该商品，不丢掉链接。

删除只排除被删除的 ID，自动补足数量，允许其他 ID 的相同图片回来。历史同图分组保留已经留下的商品，后续按照 best.id 去重；旧 ID 排除名单继续保留，但旧图片/指纹排除不再生效。历史跳过的商品需要重新搜索才能重新采集。不添加手动逐个打开的要求，不修改模板列顺序。

限制：删除主图去重不会修好名称/价格识别，也不保证详情页总能读到图片。当前实站访问此前被安全策略拒绝，不切换其他途径绕过；用受控样本验证，不声称实站已通过。
