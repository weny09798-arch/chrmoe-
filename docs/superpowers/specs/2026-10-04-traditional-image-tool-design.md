# 本地商品图片繁体转换工具

用户已选择免费本地方案：识别图片文字、OpenCC 转繁体、局部替换，效果需预览检查。目标是发给别人运行，上传图片后得到转换图，并能设置 Windows 绝对输出目录。

## 产品与数据流

独立 Windows 本地工具，浏览器界面由同机 Python 服务提供，只监听 127.0.0.1；不修改现有 Chrome 插件，不部署公共网站。用户选择多张 JPG/PNG/WebP，填写输出目录（默认工具旁的输出文件夹），点击转换。逐张串行处理，显示进度、原图/结果对比、识别原文/繁体文及跳过原因。转换结果写入指定目录且保留源图，重名时编号另存；输出 PNG 和识别检查 JSON。

RapidOCR 1.4.4 自带本地 ONNX 模型；OpenCC 提供通用/台湾/香港繁体。只有高置信度且转换文本实际变化的行参与修改。低置信度、过小、旋转或越界文本保留并给出检查提示。无需文字转换的数字/英文字行不改；同行数字和单位随文本排版保留。Pillow 使用 Windows 微软正黑体，OpenCV 在文字区域局部修补背景。边界外像素不改变，图片尺寸不改变；复杂背景、描边和艺术字体无法保证原样，预览明确标注试验版。

免费方案与此前内置模型编辑效果不同；不调用聊天图像工具/API，不要求密钥。模型初始化和所有图片处理在本机。交付可解压运行的 Windows x64 程序及源码/说明，模型和字典随包提供，离线处理。

## 边界与失败处理

仅接受同源本地请求，随机启动令牌防止外部网页触发任意路径写入。单次最多20图/总80MB，单图最长16000px、最多1600万像素；有效内容格式与后缀匹配，拒绝动画/损坏图。输出路径必须绝对路径、不得是文件；仅处理后输出生成文件，不根据上传名读取任意文件。结果预览只通过已知任务/结果 ID 读取。失败单图保留错误并继续，其余成功结果可查看；转换不可覆盖既有文件或源图。

真实引擎测试：简繁转换、低置信度不修改、数字不变、尺寸/边界外像素不变、透明通道保留、重名另存、输出目录错误和上传校验。HTTP 集成：令牌和来源限制、批量任务进度与预览授权、不泄露任意文件。用用户5张图运行真实 OCR 并查看结果；记录实际漏识别和修补局限。交付本地程序 ZIP、启动/停止/输出路径说明和样例对比页；不擅自改动 Git 1.2 标签。
