# 拼多多缺货规格与等待优化

用户目标：灰色缺货款式不能卡住采集；正常款式适当提速，保留正确的 SKU 价格和图片。

## 现场原因

商品 909991940686 的规格弹窗有 18 个款式、5 个包装选项。当前包装下只有“纯白杯碟”可选。17 个灰色款式没有 `disabled` 或 `aria-disabled` 标记，实际使用 `uRVpnTQ1` 类和 `pointer-events: none`。旧过滤遗漏这些标记，仍调用点击并对每个组合等待最多 20 次、每次约 1.2 秒。枚举的 90 个潜在组合因此长时间无进展。

现场规格区域已保存为 `tests/fixtures/pdd-saucer-stock-sku.html`。不保存登录、用户参数或页面其他内容。

## 实现

1. 增加真实禁用类及计算样式识别，保留现有语义标记检查。
2. 保留所有候选值，灰色值不能永久排除：其他颜色、包装可能使它可选。
3. 灰色较多的一组作为枚举内层，在固定包装等上下文中检查款式，减少重复切换。导出的规格列顺序保持页面原顺序。
4. 可切换的目标维度优先，不能仅因第一维当前不可选就等待。只有当前组合没有可切换的目标值，且确实有禁用值、页面不在等待加载时，才跳过此组合。一次读取可连续跳过多个这样的组合。
5. 已选状态、价格和图片均稳定三次；只有价格、图片地址都更新时，将最短等待从 4.8 秒减少到 2.4 秒。图片地址没变仍等待 4.8 秒；同价仍等待 8.4 秒。按 1.2 秒轮询，正常已更新内容至少经过三次稳定读取。
6. 缺货组合跳过数量与无法确认的规格数量分别说明，不推测价格、图片、库存或 SKU 编号。

## 验证

- 新增真实杯碟弹窗、第一维灰色但换第二维后可选、更新后快速读取测试，修改前均失败。
- 测试用受控点击反馈覆盖五种包装的价格。价格反馈并非从线上实际批量采集；测试保留真实按钮结构和禁用标记。
- 杯碟测试要求不点击灰色按钮、90 个候选组合在 65 次读取内完成、导出五种可选包装、跳过 85 个禁用组合且不点击确认。
- 提速过程中新增“价格立即变更、旧图片 complete 为 true、第四次读取后才换地址”回归，先复现失败，再要求图片已更新才提速。
- 原有延迟价格、正在加载图片、同价同图、缺货选项稍后启用、多组规格、详情图回归保留。

仅现场查看规格标记并测试真实区域回归；没有在已安装扩展中执行完整在线批量采集。不会点击确认、支付或下单。

最终验证：287 项自动测试全部通过，扩展资源及全部 JavaScript 语法检查通过，补充价格与图片均更新的保护后 37 项详情测试通过。独立只读审查未留下严重或重要问题；旧历史等待说明已标注当前版本差异。
