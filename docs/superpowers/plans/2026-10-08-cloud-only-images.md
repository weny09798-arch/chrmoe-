# 插件转换图片仅保存 OSS

用户明确要求取消插件本地存储及文件夹选择。本次沿用已完成的 OSS 替换流程，直接实施该调整。

**设计：** 新插件批次使用 `cloud_only=true`，不提交本地保存目录。本机工具在自己的任务目录缓存原图和转换图；上传成功并持久保存链接后删除对应缓存。上传失败保留缓存用于只重试上传，异常退出可恢复。完成图的对比预览从原始地址和已验证 OSS 地址获取。内容别名共用上传结果，无需复制商品目录；重新生成重新下载原图。原有已建立的本地批次和独立本地文件模式兼容。

**约束：** 未成功位置仍用原图；不自动重复付费生成；缓存清理只触及当前工具任务目录；不删除以前的本地输出或 OSS 对象。旧工具缺少云端保存能力时提示升级。软件版本 1.6.3，更新现有固定目录和单一压缩包，Git 保存历史。
