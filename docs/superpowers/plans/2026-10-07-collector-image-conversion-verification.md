# 商品采集与本地图片转换 1.6.0 验证记录

## 已完成的实现

三平台采集管理页的本机连接、文件夹选择、独立图片进度、预览、停止/继续、下载恢复/重新生成和清单导出。服务端配对凭证、来源/任务身份校验、串行下载和浏览器处理、网址及内容精确去重、按商品保存、部分失败清单、正常关闭清理及异常恢复。

原 22 列商品 Excel 代码及网络图片链接不变。图片转换清单独立输出，保存每个主图、详情图、SKU 原始位置及本地结果路径。未加入收费接口、云存储、旧 Excel 导入或水印移除。

## 验证结果

- Node 全量测试：351 项通过，0 失败，约 40 秒；脚本/资源检查通过。覆盖三平台、多图和 SKU 顺序、原工作簿不变、晚到回传、删除/清空、刷新恢复以及工具重启重新配对。重新连接只查询已有任务，失败时不会自动重新提交。
- Python 全量测试：172 项通过，0 失败，约 14 秒。覆盖文件夹取消/中文路径、凭证与来源校验、跨任务拒绝操作、失败继续、精确网址/字节去重、生成验证暂停与恢复、输出保留、超过 20 张及串行处理。
- 下载硬超时：真实本地慢速 HTTP 响应头/响应体回归通过。下载在短时子进程中执行，父进程 18 秒终止并回收；不新增浏览器工作线程。避免慢速读取阻塞清空/关闭。
- 真实 MV3 扩展联动：在独立 Chrome for Testing 153 配置中加载当前扩展，点击连接、文件夹选择回调及转换按钮，验证跨域凭证、PNG 保存、3 个主图/详情/SKU 位置复用一次结果、Blob 预览、刷新恢复、原采集对象不变。仅下载/豆包生成和原生选择边界在该界面测试中受控替换；不操作日常 Chrome 配置。
- Windows 便携程序：启动随机本机端口、配对、混合平台清单、下载失败、清空后新批次、正常退出及缓存清理通过；登录标记和输出保留。打包含 Tk/Tcl 和 openpyxl。日志不输出凭证。冻结下载子进程成功取得一张真实 CDN 图片，中文临时路径保存有效 1200×1200 JPEG，不打开浏览器。
- 真实豆包：使用已有专用 Chrome 登录，以配对接口提交一张真实商品图片，下载、上传、生成、读取完整尺寸结果、保存有效 PNG 和清单完成。未自动重试或再次生成。人工观察外部广告转为繁体，AI 水印保留。

## 审查后的修复

1. 清空原先只停止旧队列，阻塞下一批：改为检查来源和任务 ID 后取消并重建空队列，保留输出。
2. 管理页刷新丢失转换归属：会话内同步恢复最小任务/商品身份，再查询状态；删除与清空可在首次查询返回前生效。
3. 工具重启变更凭证后无法重新连接：新连接码配对后验证旧任务，确认身份再换连接，不重新提交。旧任务不存在时提供明确“忘记旧批次”，保留已采集商品。
4. HTTP 缓冲读取可超过总时限：父进程硬超时涵盖连接、响应头、响应体及图片校验，真实慢速 HTTP 测试通过。

后端和联动独立审查均批准以上修复。

## 仍需用户核对的边界

原生文件夹窗口的自动操作返回 `GetCursorPos 拒绝访问 (0x80070005)`，因此没有完成实际“取消/选目录”的桌面点选验收；实现边界测试、Tk 创建及冻结组件检查已通过。当前桌面可操作后，应在插件点击“选择保存文件夹”试选一次。

真实样图的部分包装细字仍被生成模型重绘，虽然提示明确要求保护包装。本工具不保证包装像素和文字完全保真；每个结果保留人工检查标记，默认背景和排版关闭。是否可用于上架必须对照原图检查。首次安装后的其他账号及大批量生成仍受网页、登录、验证、额度和网络影响。

验证日志、真实输出和对比截图留在本机 `artifacts`，不放进便携包或提交账号资料。
