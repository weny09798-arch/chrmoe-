# 百炼商品卖点图：配置与使用（1.6.8）

这个功能让 AI 看你上传的商品图、参考你填写的真实资料，写出卖点。你先修改确认文案，程序再把文字放在图片下方新增的白色区域。原图中的商品、包装文字、背景不重新绘制。

## 第一次配置

1. 用你自己的阿里云账号进入 [百炼控制台](https://bailian.console.aliyun.com/)，选择 **华北2（北京）** 对应的业务空间，开通该空间的模型服务与按量计费。无需购买图片翻译资源包来使用这个功能。
2. 按 [官方 API Key 获取步骤](https://help.aliyun.com/zh/model-studio/get-api-key) 创建百炼 API Key，复制保存。它与机器翻译的 AccessKey ID/Secret 是不同凭证，不要互相填到对方的配置区。
3. 在该业务空间的调用说明中找到业务空间 ID（WorkspaceId）。使用北京空间对应的 ID 和 API Key。[官方调用说明](https://help.aliyun.com/zh/model-studio/vision) 中的 `{WorkspaceId}` 需要换成这个 ID。
4. 打开插件，勾选 **生成商品卖点图**，在 **百炼卖点生成配置** 填 API Key 和北京业务空间 ID，点击保存。密钥保存到当前 Windows 用户的加密配置中，保存后输入框清空；页面只显示是否配置完成。
5. OSS 沿用你已设置的 Bucket、地域和存储凭证。如果还没配置，按 [OSS 配置说明](OSS开通与商品Excel图片替换说明.md) 操作。百炼 API Key 不能代替 OSS AccessKey。

不要把 API Key 贴到聊天、截图或发给客户。给客户的交付包没有你的密钥，客户需要填写自己的账号配置。删除百炼配置不会删除 OSS 图片或原有图片翻译配置。

## 制作一张卖点图

1. 勾选 **生成商品卖点图**，上传一张 JPEG、PNG 或 WebP 静态图片，单张不超过 10MB、2000 万像素。
2. 填商品名称。材质、规格、用途等可以补充在资料栏。图片中看不出的性能、功率、认证等参数需要你提供，系统不会要求模型猜测。
3. 点击 **付费生成卖点** 并确认。只生成文案，不重新生成商品照片。生成不确定或超时时不会自动重复调用；再次生成需要你明确确认，可能再次计费。
4. 查看标题和默认三条繁体卖点，可以改成 1～5 条。标题最多40字，每条最多60字；过长请缩短，不会截断后藏进图片里。
5. 确认后点击 **制作卖点图**。程序保留原图区域，在下方增加同宽的白色卖点栏，黑色文字、绿色点缀，高度根据文案自动增加。
6. 比较原图与结果。OSS 上传和匿名内容校验通过后，复制永久在线链接，或下载 PNG。

图片过窄、文案过长，或加字后超过现有 OSS 图片限制时，会提示调整，不裁剪商品图。原图透明区域保持透明。结果图片高于原图，这是新增文字区域产生的正常变化。

## 费用怎么理解

使用 **qwen3-vl-plus，北京，非思考模式**。输入不超过32K Token时，输入¥1/百万Token、输出¥10/百万Token。输入10000、输出500 Token的计算示例是¥0.015，**不是每张图的固定价格或费用上限**。输入图片、提示词和商品资料会计入输入；实际以百炼账单为准。[官方价格](https://help.aliyun.com/zh/model-studio/qwen3-vl-plus)

这个方案不调用每张收费的 AI 图片生成接口，也不调用原有¥0.06/张的电商图片翻译接口。文案确认后的排字在本机完成，编辑文字、重新排字和重试上传不会再次调用百炼。OSS 存储、请求及读取费用另计。

## 暂停、重试与任务恢复

- 文案生成失败：检查脱敏后的错误码、请求编号及配置。请求超时或结果不确定时可能已经计费；不能通过普通刷新自动重复生成。
- OSS 上传失败：排好字的 PNG 仍可以预览、下载。点击 **重试上传** 只上传已有图片，不重新调用 AI。
- 刷新管理页：重新连接后台后读取当前单图任务和文案；不会自动开始付费生成。
- 更换图片或清空卖点任务：旧请求不能覆盖新图片。只清理单图临时缓存，不清空采集商品、Excel 图片替换链接、密钥或已上传 OSS 对象。
- 单图功能独立使用，不需要先采集商品。本版生成的链接不会自动写入采集商品 Excel；你可以手动使用下载图片或在线链接。

## 升级

覆盖现有插件加载目录，在 Chrome 扩展程序页点击刷新并确认1.6.8；再运行交付包“本机图片转换工具/安装后台组件.cmd”，填写当前插件编号，更新后台副本。仅刷新插件不会更新已安装的后台程序。旧版本后台缺少卖点图能力时，页面会提示升级，不会改用图片翻译代替。

自动验收使用模拟百炼与 OSS，不消耗真实付费额度。真实文字准确性、账号权限和在线图片效果，需要配置你自己的账号后，用少量样图点击付费按钮检查。
