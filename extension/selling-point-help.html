百炼商品卖点图配置

这个功能识别商品图片，先写繁体卖点供你确认，再由本机程序在原图下方新增文字栏。不会重新绘制商品或包装，不自动修改采集商品 Excel。

  1. 进入百炼控制台，选择华北2（北京）业务空间并开通模型调用及按量计费。
  2. 按官方步骤创建百炼 API Key。它不是原有图片翻译或 OSS 的 AccessKey。
  3. 在北京空间的调用说明找到业务空间 ID（WorkspaceId）。参考官方调用说明。填写 ID，不能填写网址或 cn-beijing。
  4. 回插件勾选“生成商品卖点图”，展开百炼设置，填 API Key 和北京业务空间 ID并保存。沿用现有 OSS 配置；上传失败时仍可下载已排好的 PNG。

使用与费用

上传单张图，填商品名称及真实参数，点击“付费生成卖点”并确认。编辑标题和1～5条卖点，再点击“制作卖点图”。默认繁体，原图区域保持，图片下方增加白色栏。确认后可以复制 OSS 链接或下载 PNG。
