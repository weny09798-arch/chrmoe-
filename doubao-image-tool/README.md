# 豆包图片繁体转换

Windows 10/11 64 位工具。必须已安装 Google Chrome，联网使用豆包网页。

1. 解压完整便携目录，双击“启动豆包图片转换.cmd”。不要只复制 exe；旁边的 `_internal` 是运行依赖。
2. 本机页面中选择图片并填写完整输出路径，例如 `D:\图片结果`。
3. 点击“打开豆包”，在独立可见 Chrome 窗口手动登录。此登录与 Codex 侧边栏、日常 Chrome 独立。
4. 默认只转换简体文字，保留背景与排版；选项可开启背景和排版调整，额外要求可编辑。
5. 点击“开始转换”。结果为新 PNG 和配套 JSON，原图不会覆盖。检查繁体、小字、数字、单位及商品细节。

每批 1–20 张静态 JPG/PNG/WebP，总计最多 80MB；单图最多 1600 万像素、最长边 16000。选择的图片会上传给豆包，使用当前账号额度，不承诺无限免费。程序只使用正常页面上传、发送、预览和下载，不调用未公开模型接口、不绕过验证。

“停止后续提交”会保留已经发送的请求。“继续”等待同一结果；不确定提交及重启恢复必须先检查 Chrome，再点击对应图片“明确重试此图”，此操作可能重新消费额度。保存失败先修复输出位置后重试；已下载的结果尽可能直接保存。已完成结果支持单张重做，另存唯一名称。8 分钟未完成会暂停。登录、验证码、额度和页面变化需要人工处理。

登录配置和任务状态位于 `%LOCALAPPDATA%\DoubaoImageTool`，不会存入便携目录。保留该目录可保留登录；不要分享它。运行时使用同一目录的第二个实例会提示正在使用。关闭页面不等于关闭工具，请点“关闭工具”或关闭启动控制台。状态保存错误为终止状态，修复本机存储后重启；不再接受提交。

页面只在本机随机端口运行，使用随机访问凭证。结果链接供本机查看；输出文件夹是真实保存位置。刷新页面会重建当前任务，不会自动重新发送未完成请求。

## 从源码运行与构建

安装 Python 3.12 64 位，创建虚拟环境，运行 `python -m pip install -r requirements.txt`，再运行 `python run.py`。依赖按 requirements 固定版本安装。构建另外安装 PyInstaller 6.22.3，运行 `powershell -ExecutionPolicy Bypass -File build.ps1 -Python <虚拟环境的python.exe>`。构建目录默认为上一级 `artifacts\doubao-portable\DoubaoImageTool`。`--help` 显示参数；`--no-open` 可启动服务而不打开页面，仅用于检查；Chrome 始终等到用户点击或提交才启动。

便携目录包含 exe、运行依赖、web 页面、source 源码、说明和 licenses；不包含浏览器程序、模型、用户图片、测试图片、缓存或登录资料。复制整目录到另一台电脑时，该电脑需自己登录。

自动测试覆盖本机服务安全、队列及浏览器页面样本。真实豆包页面可能变化；未完成独立 Chrome 全流程人工验收前，不能视为已证明长期无人值守运行。状态/错误文字会说明需要检查的阶段。
