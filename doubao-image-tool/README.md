# 本机图片繁体转换工具 1.7.0（部署验收待完成）

源码版本 1.7.0 新增绑定单台 Windows 电脑的 30 天软件授权。首次激活开始计时，续费从当前时间与到期时间的较大值追加 30 天。授权码独立于 RAM/阿里云/OSS 密钥；所有用户含所有者均需授权。到期、停用或解绑后停止新采集与生成，已提交图片可继续保存/上传，已有结果可查看、导出；续费不会自动继续任务。

目前没有正式授权域名或服务，默认构建锁定。原交付目录中的可用 1.6.4 保持原状。激活步骤见 [客户授权说明](../docs/月度授权客户激活说明.md)，部署、构建及尚未完成的验收见 [月度授权部署与验收](../docs/月度授权部署与验收.md)。

Windows 10/11 64 位工具。支持免费豆包网页和阿里云电商图片翻译。豆包模式需安装 Google Chrome 并手动登录；阿里云模式不需要打开豆包或 Chrome。

## 1.6.1 图片选择与阿里云模式

在采集插件中可分别勾选主图、详情图、SKU 图片，默认全部选择。主图包括主图轮播组。只转换选中类型，保留原图片顺序和 SKU 对应关系；本批开始后固定选择、模式和输出位置。

“使用阿里云付费翻译”默认关闭。使用前在本工具的“阿里云图片翻译配置”区域填写自己的 AccessKey ID 与 Secret 并保存。配置使用 Windows 当前用户 DPAPI 加密，位于 `%LOCALAPPDATA%\DoubaoImageTool\aliyun-credentials.dpapi`，正常关闭与清空任务不会删除；可点击删除配置。

需要在阿里云开通机器翻译的电商图片翻译，RAM 用户至少有 `alimt:TranslateImage` 权限（资源 `*`）。勿分享密钥或上述本机配置目录。程序目录和交付压缩包不带账户配置。

插件显示按选中独立网址数 × ¥0.06/张计算的预计费用上限，点击“付费开始转换”才提交。电商图片翻译主账号每月100张免费额度、子账号共享，但工具不假定剩余额度，实际费用以阿里云账单为准。无文字图片提交也可能计费。

固定使用简体中文到繁体中文、电商模式及商品主体文字保护；本版不通过付费接口换背景或排版。图片超过10MB、宽高不在15–8192像素、长宽比达到10:1或不符合本工具静态图片限制，会明确失败，不裁剪。

提交不确定或服务端5xx会暂停，继续不会重新提交。已取得结果地址后的下载失败只重试下载；“重新生成”需再次确认，可能重复计费。停止保留已有结果地址，异常重启可恢复下载；正常关闭清除临时任务，保留配置、登录和本地输出。实体保护与繁体质量均需对照检查，不保证包装像素完全不变。

完整开通、模式选择与商品 Excel 导出说明见交付目录的“先看这里_使用说明.md”。[阿里云官方价格](https://help.aliyun.com/zh/machine-translation/product-overview/pricing-of-image-translation) · [接口和权限](https://help.aliyun.com/zh/machine-translation/developer-reference/api-alimt-2018-10-12-translateimage)

## 与商品采集插件一起使用

工具页面新增“连接码”。打开商品采集插件的图片转换区域，粘贴连接码并连接，无需选择本机文件夹，点击“转换图片”。专用 Chrome 的豆包账号仍需手动登录；程序只在你发起任务后逐张处理。

插件模式处理已采集的主图、详情图和 SKU 图片，图片数量不受普通手选模式的 20 张限制，下载和转换按顺序进行。相同网址或完全相同的图片内容只生成一次，使用工具临时缓存，上传 OSS 并匿名校验成功后自动替换商品 Excel 对应图片链接；未完成的位置保留原图。不再生成 XLSX 图片清单。免费豆包网页的 AI 水印保留。

采集进行中不能开始转换。补采的新商品不自动加入已开始的转换任务；需要再次点击转换。清空采集结果会停止对应转换，但不会删除已经保存到你指定位置的结果。遇到登录、验证码、额度或超时请在专用 Chrome 中处理后继续；“继续获取”下载同一结果，“重新生成”才会再次提交。

连接码只在当前工具进程内有效，工具重启后需要重新连接。文件夹选择和保存均发生在运行工具的这台电脑。完整步骤见交付包中的“商品采集与本地图片转换使用说明”。

1. 解压完整便携目录，双击“启动豆包图片转换.cmd”。不要只复制 exe；旁边的 `_internal` 是运行依赖。
2. 本机页面中选择图片并填写完整输出路径，例如 `D:\图片结果`。
3. 点击“打开豆包”，在独立可见 Chrome 窗口手动登录。此登录与 Codex 侧边栏、日常 Chrome 独立。
4. 只转换商品本体与包装以外的广告文字、标题、宣传横条。商品及包装上印刷的所有文字（含简体字）、品牌、数字、标签与图案保持原样；无法判断归属的文字也保留。默认保留背景与排版；可开启的背景与排版调整及额外要求只适用于商品外的区域。
5. 点击“开始转换”。结果为新 PNG 和配套 JSON，原图不会覆盖。检查商品外广告文字的繁体转换，并对照原图检查商品与包装上的文字、数字及图案。上述规则是发送给豆包的编辑要求，生成模型仍可能误改商品细节，需要预览核对。

每批 1–20 张静态 JPG/PNG/WebP，总计最多 80MB；单图最多 1600 万像素、最长边 16000。选择的图片会上传给豆包，使用当前账号额度，不承诺无限免费。程序只使用正常页面上传、发送、预览和下载，不调用未公开模型接口、不绕过验证。

“停止后续提交”会保留已经发送的请求。“继续获取此图”只等待或保存同一结果，不再次发送；“重新生成此图”会重新上传并提交，可能再次使用额度，结果另存唯一名称。不确定提交及异常重启恢复必须先检查 Chrome，再决定是否重新生成。每次新提交前会清除输入框中未发送的旧文字和附件。保存失败先修复输出位置，再继续获取。8 分钟未完成会暂停。登录、验证码、额度和页面变化需要人工处理。

下载直接读取已观察到的完整图片地址，不再启动并取消原生下载。下载任务会保留本机对话恢复信息；若专用 Chrome 意外退出，点击“打开豆包”后继续获取同一结果。异常重启时，有明确恢复链接的下载任务也可继续获取，不重新提交；正常关闭并清空任务仍会删除该恢复信息。已取得的图片不会因为关闭预览失败而丢失。

登录配置和任务状态位于 `%LOCALAPPDATA%\DoubaoImageTool`，不会存入便携目录。不要分享该目录。运行时使用同一目录的第二个实例会提示正在使用。关闭页面不等于关闭工具，请点“关闭工具并清空任务”：工具会停止当前操作，再清除任务记录、上传缓存和下载缓存，下次从空任务开始；豆包登录、在线对话和输出文件夹中的已保存图片保留。也可以点“清空任务 / 开始新一批”回到空任务状态，这会关闭专用 Chrome，下一次可重新打开而无需清除登录。状态保存错误也可以尝试清空任务，若本机存储无法清理则显示错误。

页面只在本机随机端口运行，使用随机访问凭证。结果链接供本机查看；输出文件夹是真实保存位置。刷新页面会重建当前任务，不会自动重新发送未完成请求。异常结束进程时可能保留恢复状态；可在重新启动后点击清空任务。

## 从源码运行与构建

安装 Python 3.12 64 位，创建虚拟环境，运行 `python -m pip install -r requirements.txt`。依赖按 requirements 固定版本安装，包括直接用于授权的 cryptography 和 requests。未配置授权时运行工具保持锁定。构建使用 `build.ps1 -Python <虚拟环境的python.exe> -EvaluationLocked` 生成明确标识的隔离锁定评估包；正式候选构建必须提供 `-PublicConfig <仅包含 server_url/public_key 的 JSON>`，缺失或不安全配置在打包前失败。仅允许写入本工作树 `artifacts/` 下的新目录，不覆盖旧包、不生成客户 ZIP。重新构建应使用源码仓库中的构建脚本；包内只附运行源码白名单。详见部署与验收文档。`--state-dir` 可指定隔离配置目录；评估不得使用默认 `%LOCALAPPDATA%\DoubaoImageTool`。Chrome 等到用户点击或提交才启动。

便携目录包含 exe、运行依赖、web 页面、source 源码、说明和 licenses；不包含浏览器程序、模型、用户图片、测试图片、缓存或登录资料。复制整目录到另一台电脑时，该电脑需自己登录。

2026-10-04 已用独立工具完成五张原图的上传、生成与保存实测，原图保持不变。实测出现附件和完整图片加载暂停，继续后使用同一结果保存；完整图片等待已改为分段等待最多 30 秒。详见 VERIFICATION.md。

这证明生成和保存流程可用，不代表全部文字转换准确，也不保证长期无人值守。实测仍有简体字漏转、包装小字错误，结果必须检查，必要时使用“单张重做”补充要求。豆包页面、登录、验证码、额度及网络变化可能需要人工处理。

## 1.6.2：采集插件的图片链接替换

插件发起的批次需要先在本机页面配置 OSS Bucket、地域和凭证，再点击检查上传与公开读取。检查会上传一张小测试图，可能产生少量 OSS 请求费用；保存配置不上传。集成批次的每张转换图临时缓存后上传并校验，成功链接同步到插件商品任务，导出 Excel 自动替换对应位置。未成功的位置保留原图。“重试上传”不会重新调用豆包或付费翻译。独立选择本地文件转换沿用本地保存流程。

OSS 凭证也使用 Windows 当前用户 DPAPI 加密，不进入插件或交付包。关闭工具保留配置和本地结果；插件里已持久保存的链接不丢失。OSS 链接不自动删除或过期。内部 JSON 记录用于恢复，不再生成 XLSX 图片清单。

## 1.6.3：采集图片仅云端保存

新版插件不提交本地输出目录，转换图片直接保存 OSS。上传失败保留工具临时图片以便重试；成功且链接持久保存后清理原图和转换图缓存。预览读取原网址与 OSS 图片。独立手选文件和旧批次保持各自的原配置；历史输出文件不删除。

## 1.6.4 分类数量限制

插件可分别限制主图、详情图、SKU 图片的前 N 个位置，留空全部。工具先按类型和数量保序选择，再去重；任务保存限制并在恢复时沿用，失败不向后补图。豆包采集批次同样上传 OSS 并发布 Excel 替换链接，本地仅为临时缓存。独立手动选本地文件的入口保持原有本地输出。
