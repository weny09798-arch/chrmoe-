# 本机图片转换后台组件 1.6.7

适用于 Windows 10/11 64 位，支持免费豆包网页与阿里云电商图片翻译。交付目录历史名称仍为“商品采集与图片转换_1.6.1”，内容版本为 **1.6.7**。保留完整目录，`_internal` 是运行依赖，不要只复制 EXE。

## 插件使用：安装一次，之后自动启动

1. 在 Chrome 加载“商品采集插件”，打开管理页，从安装帮助点击“复制插件编号”。
2. 双击本目录“安装后台组件.cmd”，粘贴完整 32 位编号，无需管理员权限，只登记当前插件。
3. 回插件点击“重新连接”或重开管理页。以后只操作插件，无需日常运行启动 CMD 或复制连接码。后台启动不打开豆包、不提交图片、不检查 OSS。
4. 在插件“图片服务设置”保存阿里云及 OSS 配置。只有明确点击 OSS 检查才上传小测试图，可能产生少量请求、存储和读取费用。配置继续用 Windows 当前用户 DPAPI 加密，保存后清空输入框，状态不返回 Secret，不存入 Chrome 存储或交付包。
5. 采集结束后选择主图、详情图、SKU 图及各类前 N 个位置，留空全部；先限量再去重，失败不向后补图。豆包需点击“打开豆包”，在专用 Chrome 登录、处理验证；阿里云无需打开豆包。明确开始后逐张处理，不自动开始或切换付费服务。

默认只把商品及包装外广告文字转繁体。“同时转换商品及包装文字”默认关闭，开启后两种服务都处理包装文字；数字、单位、原意与外观仍要求保持。背景、排版调整仅为豆包选项。每张结果需人工核对，免费豆包的 AI 水印保留。

插件批次上传自己的 OSS，公开读取校验通过才发布 Excel 替换链接；未完成位置保留原图，无需本机输出目录。相同网址或内容只生成一次，各商品和 SKU 关系分别保存。链接持久保存后清理图片缓存，上传失败保留缓存，“重试上传”不再翻译。部分完成可导出，XLS/XLSX 模板、价格和 SKU 行不变，不生成图片转换清单.xlsx。

## 自动后台的关闭、恢复、更新和卸载

关闭或刷新管理页不清空任务。完全退出 Chrome 或原生连接断开后有 **30 秒宽限**，持续断开停止新提交；已提交图片继续取回、上传和保存，收尾等待最多 **600 秒**，然后保留恢复记录退出。浏览器自身结束可能另需有上限的时间。重新打开仅恢复状态，须明确点击继续，不重复不确定的付费提交。其他采集来源的旧任务不会写入新商品。

“清空转换任务”安全结束处理后清除临时记录和缓存，保留登录、DPAPI 配置、OSS 对象及插件已保存链接。用户数据默认位于 `%LOCALAPPDATA%\DoubaoImageTool`，安装程序目录为 `%LOCALAPPDATA%\ProductCollectorBackend`。不要分享用户数据目录。

更新前停止后续提交并等待当前结果保存，覆盖原插件加载目录后重新加载，确认 1.6.7；再运行新版“安装后台组件.cmd”，粘贴现有插件编号以更新已安装的后台副本。只刷新插件不会更新后台副本。重复安装更新同一后台目录并保留 DPAPI 配置、登录及任务记录，后台仍在收尾时提示等待，原组件保留。目录变动导致编号改变时重新登记。

“卸载后台组件.cmd”移除本组件登记及程序，保留配置、登录、任务记录和 OSS 对象。仍在安全收尾时等待后再试。不设置开机启动，不安装 Windows 系统服务。

## 阿里云配置与费用

开通机器翻译的电商图片翻译，RAM 用户至少有 `alimt:TranslateImage` 权限，资源 `*`，在插件“图片服务设置”填写 AccessKey ID 和 Secret。OSS 可复用翻译凭证或用独立凭证。保存不调用翻译，付费开始确认才提交。电商资源包与通用资源包不同。

按 2026-10-08 查阅的官方价，电商图片翻译后付费参考价 **0.06 元/张**，主账号每月 100 张免费额度、子账号共享。预览按选中独立网址数计算初始上限，不假定剩余额度；账单为准，无文字图片也可能计费。

固定简体中文 → 繁体中文、电商模式。默认商品主体过滤开启，包装文字开关启用后关闭过滤，仍用电商版。图片最多 10MB、宽高 15～8192 像素、长宽比小于 10:1；沿用静态图片限制，违规明确失败，不裁剪。杭州地址为 `mt.cn-hangzhou.aliyuncs.com`。

提交不确定或服务端错误会暂停，普通继续不重提；已取得结果地址后只重试下载。“重新生成”可能再次计费，需确认。停止及自动退出保留可恢复状态，文字质量和商品保护结果需人工检查。

[官方价格](https://help.aliyun.com/zh/machine-translation/product-overview/pricing-of-image-translation) · [接口和权限](https://help.aliyun.com/zh/machine-translation/developer-reference/api-alimt-2018-10-12-translateimage)。完整流程见交付目录“先看这里_使用说明.md”和“OSS开通与商品Excel图片替换说明.md”。

## 1.6.7 阿里云错误诊断

后续错误只保留安全原因、服务错误码、HTTP 状态和请求 ID；字段缺失或含敏感内容时不显示，不回显原始 SDK 异常、响应、密钥或带签名的链接。请求网络超时/连接失败表示未取得可靠结果；服务返回错误可结合错误码检查账号权限、额度和服务状态；结果内容无效表示没有取得有效结果地址；本机处理进程超时、返回内容无效或异常退出用于区分本机辅助进程问题。提交不确定仍可能已计费，继续和重连不会自动重新提交。

旧批次第二张的原因仍未知，缺少结果地址时不能通过继续恢复；更新不能补回历史诊断，也没有重新转换该图。保留暂停记录和第一张已发布结果。需要再试时，仅对第二张明确选择“重新生成”并再次确认付费，可能再次计费。保存设置不生成图片。

## 独立选本机图片：兼容流程

这是单独的本机选图入口，采集插件日常无需运行。旧版插件可用此页面的手动连接码，当前进程重启后失效；新版插件使用上面的自动安装连接流程。

1. 双击“启动豆包图片转换.cmd”，在独立本机页选择图片与完整输出目录，例如 `D:\图片结果`。
2. 豆包模式打开专用 Chrome 登录；阿里云模式在独立页配置凭证并确认费用。
3. 默认仅转换商品外广告文字，可勾选商品及包装文字。结果另存 PNG 与 JSON，不覆盖原图，逐张检查文字、数字及图案。

每批 1～20 张静态 JPG/PNG/WebP，总计最多 80MB，单图最多 1600 万像素、最长边 16000。豆包用当前账号额度，不承诺无限免费，不绕过登录或验证。8 分钟未完成会暂停。

“停止后续提交”保留已发送请求，“继续获取此图”取回同一结果，“重新生成此图”重新上传提交，可能再次使用额度，结果另存唯一名称。保存失败先修复输出目录。异常重启且有明确恢复链接时可继续下载，不重提；不确定时先检查专用 Chrome。

独立页关闭不等于程序退出。“关闭工具并清空任务”安全停止后清除临时任务及缓存，保留登录、在线对话、凭证和输出图片；“清空任务 / 开始新一批”也清理任务并关闭专用 Chrome。此显式清空与新版自动后台退出保留恢复记录分开使用。

## 从源码运行与构建

安装 Python 3.12 64 位，创建虚拟环境，运行 `python -m pip install -r requirements.txt`，再运行 `python run.py` 启动独立页。构建另外安装 PyInstaller 6.22.3，运行 `powershell -ExecutionPolicy Bypass -File build.ps1 -Python <虚拟环境的python.exe>`。默认输出为上一级 `artifacts\doubao-portable\DoubaoImageTool`。

`--help` 显示参数，`--no-open` 不打开页面；安装后的自动模式由 Native Messaging 启动，不开独立管理页。便携目录含程序、依赖、source 源码、安装/卸载入口、说明及许可证，不含浏览器、模型、用户配置、图片、缓存、任务或登录资料。
