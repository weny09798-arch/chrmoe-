本机独立工具

豆包图片繁体转换

只将商品外的广告文字转成繁体；商品及包装上的文字、品牌、数字与图案保持原样。

连接商品采集插件

在采集插件的图片转换面板粘贴连接码。工具重启后请重新复制连接码，每次仅与一个插件配对。

阿里云图片翻译配置

阿里云图片翻译按 ¥0.06/张计费，图片将上传阿里云。开通服务后填写 AccessKey；保存配置不会发起收费调用。凭证由 Windows DPAPI 加密，仅供当前 Windows 用户读取。

阿里云图片须为静态 JPG / PNG / WebP，每张不超过10MB，宽高均为15–8192像素，长宽比小于10:1；还需符合本工具1600万像素限制。超限图片会跳过，不裁剪。实体保护是服务参数，包装文字和画面仍需逐张检查。

OSS 图片链接配置（商品 Excel 自动替换）

从采集插件发起的豆包和阿里云转换图都保存到你的 OSS，本机仅保留处理中临时缓存。只有上传并校验成功的图片才替换 Excel 链接；中途停止时其余图片仍使用原图。下方独立选择本地图片的入口仍保存到本机。OSS 存储、请求和流量单独计费。

尚未配置

在 OSS 控制台创建专用标准存储 Bucket，读写权限保持“私有”，关闭该 Bucket 的“阻止公共访问”，不开启版本控制。给 RAM 用户授予此 Bucket 下 converted-images/* 的上传权限。工具仅将转换图片设为公共读，不改变整个 Bucket 的权限。复用翻译密钥也需增加 OSS 权限。检查按钮会上传一张小测试图片，可能产生少量请求费用；保存配置不会上传。完整步骤见交付包中的《OSS 开通与商品 Excel 图片替换说明》。

1 · 选择图片与保存位置

静态 JPG / PNG / WebP，总计不超过 80MB，每张不超过 1600 万像素。

请填写运行工具这台电脑上的完整路径；原图不会覆盖，结果保存为“原名_繁體.png”。

2 · 打开豆包并登录

在打开的独立 Chrome 窗口手动登录一次。此登录与 Codex 侧边栏独立，登录信息仅保存在本机。

3 · 开始转换与检查结果

所选图片会发送到所选服务。请检查商品外广告文字的繁体转换，并对照原图检查包装上的文字、数字与图案是否保持原样。阿里云不执行额外改图要求或背景与排版调整。

尚未开始

阿里云“继续获取”只下载已有结果；提交不确定时继续不会重新提交。“重新生成此图”会再次收费并要求确认。清空任务会关闭专用 Chrome，保留登录、阿里云及 OSS 配置和已保存的图片。关闭工具会清除任务记录与临时图片，下次从空任务开始。
