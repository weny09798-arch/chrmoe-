豆包图片繁体转换

将商品图片中的简体文字转换为繁体，默认保留商品、背景与排版。

1 · 选择图片与保存位置

静态 JPG / PNG / WebP，总计不超过 80MB，每张不超过 1600 万像素。

请填写运行工具这台电脑上的完整路径；原图不会覆盖，结果保存为“原名_繁體.png”。

2 · 打开豆包并登录

在打开的独立 Chrome 窗口手动登录一次。此登录与 Codex 侧边栏独立，登录信息仅保存在本机。

3 · 开始转换与检查结果

开始后，所选图片会发送到豆包并使用当前账号额度。生成文字可能有误，请检查繁体、数字与商品细节。

尚未开始

提交状态不确定或程序重启后，先检查 Chrome，再明确重试该图片。继续不会重新提交不确定的请求。
